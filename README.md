# MERN Course Management System

A full-stack **MERN (MongoDB, Express, React, Node.js)** application to manage courses with complete CRUD functionality.

Features

- Add new courses
- View all courses
- Update existing courses
- Delete courses
- Search courses by category
- Sort courses by duration
- Form validation (frontend + backend)
- RESTful API design
- Persistent MongoDB storage

Tech Stack

Frontend
- React.js
- Axios
- Bootstrap

Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
